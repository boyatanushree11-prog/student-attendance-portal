# Student Attendance Portal (Python FastAPI)

An advanced, Lightweight Student Attendance Management System written entirely in Python, utilizing FastAPI, SQLAlchemy, and Tailwind CSS.

## Features
- Add and manage student records with unique Roll Numbers.
- Mark and update attendance status (Present, Absent, Late).
- Date-wise historical attendance views.
- Real-time database metrics dashboard.
- Automatic database table creation and seed data.

## Requirements
- Python 3.8 or higher installed on your machine.
